## Architecture decisions frozen through M10

1. M8 owns objective semantics.
2. M9 owns compatibility Ridders+BFGS MAP optimization.
3. M10 owns numerical Hessian, covariance/correlation, Laplace evidence, fit criteria, and LME-based restart selection.
4. Native GPU/autodiff optimization remains a separate future engine and must be cross-validated against compatibility mode.
