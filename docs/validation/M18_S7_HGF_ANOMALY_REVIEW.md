1. regenerate the immutable S7 shard and verify its frozen shard/case hash;
2. reproduce the standard MATLAB and HGFX fit from the unchanged default transformed start;
3. evaluate the same objective at the exact MATLAB endpoint and exact HGFX endpoint in both implementations;
4. run the frozen MATLAB quasi-Newton optimizer directly from the default free start;
5. rerun MATLAB from exactly one local binary64 spacing (`eps`) below and above each of the three free start coordinates, yielding exactly six variants.

The existing numerical-equivalence gate is reused unchanged:

`abs(diff) <= 3e-10 + 3e-8 * abs(reference)`.

No wider tolerance or decimal-place rule is introduced.

## Classification

Per case:

- `SHARED_OBJECTIVE_MISMATCH`: same-vector objective replay fails the existing gate. This is implementation evidence and blocks reference-limitation classification.
- `MATLAB_START_ULP_SENSITIVE_PAIRING`: shared-objective replay passes and at least one one-spacing MATLAB start perturbation changes either the fitted endpoint beyond the existing gate or the inferred convergence outcome. This is exact-case reference-optimizer sensitivity evidence.
- `PAIRED_ENDPOINT_WITHIN_GATE`: endpoint and convergence outcomes already agree within the existing gate.
- `STABLE_REFERENCE_OPTIMIZER_MISMATCH`: the paired endpoint/convergence anomaly remains, shared-objective replay passes, and no material MATLAB one-spacing sensitivity is observed. This requires S8 optimizer investigation/repair.
- `INSUFFICIENT_REFERENCE_EVIDENCE` / `INVALID_BASELINE_REPLAY`: the diagnostic contract or baseline cannot be reproduced.

Overall `REFERENCE_LIMITATION_REVIEW_SUPPORTED` is allowed only when every frozen anomaly has shared-objective parity and each unresolved paired anomaly is accompanied by exact-case MATLAB start sensitivity. It is evidence for the separate S7 review; it is **not** a retroactive S7 PASS.
