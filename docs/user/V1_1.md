# HGFX 1.1 beta usage

Version in package metadata: **1.1.0b1** (`pyproject.toml`).
Source for the 1.1 feature line starts at `b74a3199077d0afc7af730d32b19cb3f158f9516`.
The first planned public prerelease is `v1.1.0b1`. Until that tag is validated and published, PyPI remains stable `hgfx==1.0.0`.

**Status:** BETA CANDIDATE PREPARATION / NOT YET PUBLISHED.

The 1.1 line is additive. `hgfx.fit_model` remains the frozen MATLAB 8.2.0 quasi-Newton compatibility path used for v1.0.0 and paper-1 reproduction. The new 1.1 APIs are opt-in additions and do not enlarge or rewrite the frozen v1.0.0 equivalence evidence.

The release policy and beta gate are documented in `docs/planning/VERSION_POLICY.md` and `docs/planning/V1_1_RELEASE_PLAN.md`. Tracking issue: #56. Project-specific prior numbers stay in the analysis repos, not here.

| Need | Call |
|---|---|
| Repeat MATLAB / paper-1 numbers | `hgfx.fit_model` |
| Tighter MAP on the stock binary+unitsq slice | `hgfx.optim.fit_map` |
| Tighter MAP on *your* negative log-joint | `hgfx.optim.minimize_map` / `multi_start_map` |

## Opt-in MAP

SciPy `L-BFGS-B` is the default engine when SciPy is installed. Without SciPy the internal L-BFGS is used.

```python
from hgfx.optim import MapOptions, fit_map, minimize_map, multi_start_map

# Same objective as fit_model, different optimizer.
fit = fit_map(y, u, n_random_starts=8)
print(fit.neg_log_joint, fit.free_parameters, fit.full_parameters)

# Any scalar objective (dual-stream wrapper, VKF + softmax, ...).
result = multi_start_map(
    neg_log_joint,
    x0,
    n_random_starts=8,
    options=MapOptions(solver="scipy", method="L-BFGS-B", gradient="finite"),
)
print(result.x, result.fun, result.success, result.solver)
```

`MapOptions`:

- `solver`: `"scipy"` (default) or `"internal"`
- `method`: SciPy method, default `"L-BFGS-B"`
- `gradient`: `"finite"` (default), `"ridders"`, or `"jax"` (JAX-traceable objectives only)
- `gtol=1e-8`, `ftol=1e-12`, `maxiter=800`

Pass `jac=` when you have an analytic or JAX gradient of your wrapper.

Details: `docs/planning/OPT_IN_MAP.md`.

## Dual-stream AR1 binary

Two stock `hgf_ar1_binary` (or e/u) forwards. No new perceptual equation.

`u` must have at least two columns: reward in column 0, social/advice in column 1.

```python
from hgfx.models import dual_ar1_binary, hgf_ar1_binary

traj, inf = dual_ar1_binary(
    u,
    reward_parameters,   # same vector as a single hgf_ar1_binary call
    social_parameters,
    update_type="hgf",   # or "ehgf", "uhgf"
    transformed=False,
    validate=False,
)
```

`inf` shape is `(n_trials, n_levels, 4)`:

| index | content |
|---|---|
| `inf[:, :, 0]` | reward `muhat` |
| `inf[:, :, 1]` | reward `mu` |
| `inf[:, :, 2]` | social `muhat` |
| `inf[:, :, 3]` | social `mu` |

Social softmax reads reward prediction at `inf[:, 0, 0]` and social prediction at `inf[:, 0, 2]`. The `mu3` variant reads level 3 from `inf[:, 2, 0]` and `inf[:, 2, 2]`.

`traj` keys are the single-stream names with `_r` / `_a` suffixes (`muhat_r`, `muhat_a`, ...).

## Volatile Kalman Filter

Piray & Daw binary VKF. Native parameters per stream: `[lambda, v0, omega]`.
If `transformed=True`: `lambda = sgm(p)`, `v0 = exp(p)`, `omega = exp(p)`.

```python
from hgfx.models import vkf_binary, vkf_reward_social

traj, inf = vkf_binary(u_reward, [0.2, 0.1, 0.1], transformed=False)
# traj: muhat, mu, vol, al, da
# inf: (n, 2) = [muhat, mu]

traj, inf = vkf_reward_social(
    u[:, :2],
    [lam_r, v0_r, om_r, lam_a, v0_a, om_a],
    transformed=False,
)
```

`vkf_reward_social` `inf` is `(n, 1, 3)`:

- `inf[:, 0, 0]` reward predicted belief
- `inf[:, 0, 1]` reward posterior belief
- `inf[:, 0, 2]` social predicted belief

This matches `tapas_softmax_binary_socialreward4` in Belief-updating.

## Social-gaze softmax

Transformed observation parameters: `[zeta, beta, eta]`.
Native: `zeta = exp`, `beta = exp`, `eta = sgm`.

`u` needs four columns:

0. blue card correct (`1/0`)
1. advice correct (`1/0`)
2. blue reward value
3. green reward value

`y` is follow-gaze (`1`) vs not (`0`).

```python
from hgfx.responses import softmax_binary_socialreward

logp, yhat, res = softmax_binary_socialreward(
    y,
    inf,
    ptrans=[0.0, 0.0, 0.0],
    inputs=u,
    irregular_trials=None,
    variant="beta",   # socialreward4; use "mu3" for variant 1
)
```

`variant="beta"`: constant inverse temperature.
`variant="mu3"`: `beta * exp(-mu3_r - mu3_a)`.

## 3PLR card-volatility softmax

One transformed parameter: `beta = exp(ptrans[0])`.

`gamma_i(t) = beta * exp(-muhat_3_i(t))`

`y` is the chosen card in `{1, 2, 3}`.

```python
from hgfx.responses import softmax_mab3_card_volatility

logp, yhat, res = softmax_mab3_card_volatility(
    y,
    inf,                 # 4-D MAB infStates preferred
    ptrans=[0.0],
    predorpost=1,
)
```

Accepted `inf` layouts:

- 4-D MAB: `inf[:, 1, :, pred]` values, `inf[:, 3, :, 1]` log-volatility (MATLAB 1-based)
- 3-D with 3 trailing slices, or 6+ trailing slices using indices `(1,3,5)`

Perceptual model for 3PLR remains `hgf_ar1_binary_mab` / `ehgf_...` / `uhgf_...` from v1.

## Typical analysis wiring

Belief-updating two-card HGF:

```python
from hgfx.models import dual_ar1_binary
from hgfx.optim import multi_start_map
from hgfx.responses import softmax_binary_socialreward
from hgfx.responses.base import total_log_likelihood

def neg_log_joint(p):
    p_r, p_a, p_obs = split(p)          # your split; priors stay in the analysis repo
    _, inf = dual_ar1_binary(u, p_r, p_a, validate=False)
    logp, _, _ = softmax_binary_socialreward(y, inf, p_obs, inputs=u, variant="beta")
    return -total_log_likelihood(logp) + prior_penalty(p)

fit = multi_start_map(neg_log_joint, x0, n_random_starts=8)
```

Belief-updating two-card VKF:

```python
from hgfx.models import vkf_reward_social

def neg_log_joint(p):
    _, inf = vkf_reward_social(u[:, :2], p[:6], transformed=True)
    logp, _, _ = softmax_binary_socialreward(y, inf, p[6:9], inputs=u, variant="beta")
    return -total_log_likelihood(logp)
```

3PLR:

```python
from hgfx.models import hgf_ar1_binary_mab
from hgfx.responses import softmax_mab3_card_volatility

traj, inf = hgf_ar1_binary_mab(u, p_perceptual, validate=False)
logp, yhat, res = softmax_mab3_card_volatility(y, inf, p_obs)
```
