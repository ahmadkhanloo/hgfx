Reference MATLAB eHGF source uses `max(0, correction)`, while released HGFX 1.0.0 uses `np.maximum(0.0, correction)`. For this NaN correction, MATLAB `max` keeps the finite zero; NumPy `maximum` propagates NaN. The original MATLAB `pi3=1/sa3` equals `pihat3=1/sahat3`; see [MathWorks max reference](https://www.mathworks.com/help/matlab/ref/double.max.html) and the MathWorks example `max(3,NaN)=3` [here](https://www.mathworks.com/matlabcentral/fileexchange/44702-max-and-min-keeping-nans). These derived intermediate terms were **not independently instrumented** in the original runtime; exact causal attribution remains subject to domain-expert review.
