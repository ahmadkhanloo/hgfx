This supplement will execute both original public fit paths in a single GitHub Actions Ubuntu runner job, without patching either frozen optimizer source. The frozen HGFX `fit_model` is called native once and with a transparent temporary wrapper around `FitProblem.evaluate_free` once; the wrapper must call the original method **exactly once per request**. Direct calls are identified from immediate Python frozen `quasinewton_optim` source file/function and source lines, and indirect calls from original Ridders/differentiation are counted separately. The source Python optimizer frame is optionally line-traced to observe **executed** statements `break` on successful Armijo, accepted-state assignment, reset, and exit reason, rather than inferring `if` conditions from a post-hoc calculated margin. The same runner also executes native and callback-wrapped original frozen MATLAB 8.2.0 `fitModel` using existing validated `subject7_actual_optimizer_calls_matlab`; no replacement objectives or optimizer source modifications. These separate actual calls on the same runner are ***two independent public fits***, not cross-language shared objective evaluations.
