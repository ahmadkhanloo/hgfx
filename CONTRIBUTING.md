# Contributing

HGFX is scientific software. Contributions are reviewed for both software quality and numerical/scientific correctness.

## Before opening a PR

- Reference a Migration Matrix ID.
- Include tests.
- Include golden-reference evidence when changing mathematical behavior.
- Document numerical differences.
- Do not weaken tolerances without justification.
- Preserve third-party provenance.

See `.github/PULL_REQUEST_TEMPLATE.md`.
