\texttt{4dd8fbd8239d05f2c7932a9a9b3b7795f0a9ab27}.

The MATLAB oracle is 8.2.0 at

\texttt{2437f4dc241541072722a2695ddeca7b44d83dd3}. These identities
define the scope; current development features are not included.
Original numerical experiments were not rerun for this revision.

Candidate figures regenerate with \texttt{python\ generate\_figures.py}
from this directory. The agreement/accuracy figure is redesigned from
the frozen decision; recovery is redrawn in grayscale from the decision,

\subsection{S2 Fitting and recovery}\label{s2-fitting-and-recovery}

The official stress-fit D02 and holdout D08 are preserved failures,
classified as matched reference limitations, not direct parameter
parity. Their decision files and frozen source runs remain in the
reference validation directory. No endpoint was forced, no trial was
silently discarded and no tolerance was changed here. The historical M18
scientific failure remains separate from paired S7 accounting.

The paired grid has 72 parameter cases and 36 model-recovery datasets
with three candidate fits each. There are 12 shards, two trial lengths
(128,256), two truth scales (0.15,0.35 prior SD), six parameter
replicates per stratum and three model replicates per stratum. The
selection rule is minimum BIC. Metrics rounded for display; full
precision remains in the frozen decision:

\subsection{S3 Trial-horizon
integrity}\label{s3-trial-horizon-integrity}

The original run 35272347167 contains 24 shards, 144 parameter cases and
72 model cases. The overall gate is false. Both winner agreement and the
free-index contract fail. Ten BIC winners differ, confined to classic
HGF at 512/1024 trials; the aggregate per-model mismatch classification
covers all three families. Invalid classic-HGF trajectories remain in
the denominator; undefined metrics remain gaps. A favorable diagnostic
row is not an aggregate scientific success.

\texttt{07b45a569e04e8e71244c5310dd2cc53dbb2b0ec}, Python 3.12.13,
JAX/JAXLIB 0.11.1. Two Tesla T4 devices were visible; four required
fitting cells ran on cuda:0. Residency checks and enumeration are

source/runtime identity. The maximum gaps are 0.006783711260709424

\subsection{S6 Applied feasibility and source
routes}\label{s6-applied-feasibility-and-source-routes}

Pain source commit is \texttt{3f1d32aff73826a1385c359ca638ad0e11a7fda7};
all 504 tracked files are hashed in its source manifest. Its exact
likelihood/config license and historical environment remain unresolved.
Some simulation files carry GPL notices; no source was translated into
MIT code. The missing plotting helper and filename/declaration
mismatches remain recorded. Input-name confusion was resolved using the
actual source table path, without manufacturing data.

SPIRL source commit is
\texttt{86fd5122a744acfb5bc7ba12720426d8b4aa0ffa}. Its custom eHGF and
seven joint choice/RT response models require a separate migration. The
recorded original settings include 399 random starts and MATLAB R2019b;
using standard eHGF or dropping RT is a changed analysis.

No published-study fit or new recovery was executed. The clean-wheel
quickstart is synthetic workflow evidence only. Unlicensed external
files remain local and ignored; public manifests contain hashes and URLs
rather than participant values. The historical acquisition dossier
remains unchanged.
